# Play Console › 앱 콘텐츠 답변 메모

## 데이터 보안 (Data safety)
- 앱이 사용자 데이터를 수집하거나 공유하나요? → **예 (수집)**, 제3자와 **공유하지 않음**
- 전송 중 암호화? → **예** (Firebase 는 HTTPS 만 사용)
- 사용자가 데이터 삭제를 요청할 수 있나요? → **예** (앱 안: 메뉴 › 계정 › 계정 삭제 / 웹: privacy.html#delete)
- 수집 항목
  | 유형 | 항목 | 필수/선택 | 목적 |
  |---|---|---|---|
  | 개인 정보 | 이메일 주소 | 선택 (계정을 만들 때만) | 계정 관리 |
  | 앱 활동 | 기타 사용자 제작 콘텐츠 → 게임 진행(세이브) | 선택 | 앱 기능 (다른 기기에서 이어하기) |
- 위치, 연락처, 사진, 결제, 기기 ID, 광고 ID: 수집 안 함
- 분석·광고 SDK: 없음

## 계정 삭제 (Account deletion)
- 앱 안에서 계정 삭제 가능: 메뉴(☰) › ☁️ 계정 › 계정 삭제
- 웹 URL: https://dkskhjs.github.io/Mycoom/privacy.html#delete

## 콘텐츠 등급 (IARC 설문)
- 폭력·성적 내용·욕설·약물·도박: 없음
- 사용자 간 소통·공유: 없음 (채팅 없음)
- 개인정보 공유: 없음
- 예상 등급: 전체이용가 / PEGI 3

## 타겟층
- 대상 연령: **13세 이상** 선택 권장 (13세 미만을 포함하면 '가족 정책' 추가 요건이 붙음)
- 아동이 관심을 가질 만한 요소: 귀여운 도트 그림이 있으므로 '의도치 않게 아동의 관심을 끌 수 있음' 질문에 사실대로 답변

## 광고
- 광고 포함? → **아니요**

## 앱 액세스 권한
- 모든 기능이 로그인 없이 사용 가능 → "특별한 액세스 권한 없음" (로그인은 선택 기능)
