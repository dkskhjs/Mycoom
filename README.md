# 스팀 & 빈즈

스팀펑크 도시의 빈 땅을 사서 배관을 깔고, 인테리어를 하고, 카페를 운영하는 도트 타이쿤 게임입니다.
빌드 과정 없이 `index.html`을 브라우저로 열면 됩니다 (`file://`로 열어도 동작).

## 게임 흐름

1. **땅 구매**: 크기·가격·유동인구가 다른 세 필지 중 하나를 고르고, 주인공(남/여)을 고릅니다.
2. **🔧 설비**: 중앙 증기 보일러 하나로 모든 설비를 돌립니다. 전기는 없습니다.
   - 왼쪽 벽의 **수도 인입구** → 보일러: **급수관**
   - 보일러 → 에스프레소 머신·주전자·오븐·싱크대: **급탕(증기)관**
   - 보일러 → 바닥 아래: **온수난방관** (깔린 칸이 따뜻해짐) / 주철 라디에이터
   - 배관이 설비 **밑이나 바로 옆 칸**을 지나가면 연결됩니다. 설비 탭에서는 바닥이 어두워지고 배관이 보입니다.
   - 보일러는 석탄을 태웁니다. 난방 칸이 많을수록, 눈보라일수록 빨리 탑니다.
3. **🎨 인테리어**: 바닥·벽·천장 마감재(드래그로 칠하기), 주방 설비, 가구, 장식, 천장 조명.
   가구는 바닥재 위에만 놓을 수 있고, 의자는 테이블과 상하좌우로 붙어야 좌석이 됩니다.
   마감재와 장식은 **분위기 점수**를 올려 손님 수와 팁을 늘립니다.
4. **☕ 운영**: 체크리스트(보일러·급수·석탄·카운터·위생 싱크대·조리 설비·좌석)를 채우면 영업 시작.
   설비를 눌러 메뉴를 만들고, 완성 말풍선을 눌러 카운터로 옮기면 바리스타가 손님에게 가져다줍니다.
   손님 만족도 = 분위기 + 실내 온도 − 기다린 시간 → 팁과 평판에 반영됩니다.
5. **🛒 상점**: 원두·우유·찻잎·밀가루·코코아·석탄 구매.

6. **🏗 공간 확장**: 상점 탭에서 동쪽(+2열)/북쪽(+2행) 확장. 필지마다 최대 크기가 있고, 확장할수록 공사비와 필요 레벨이 오릅니다. 영업 전에만 공사 가능.
8. **☕ 커피 얼룩**: 손님이 다 마시고 일어날 때 가끔 좌석 옆 바닥에 커피를 쏟습니다. 얼룩 하나당 분위기 −2, 얼룩 옆 좌석 손님은 만족도 −5. 얼룩을 클릭하면 닦입니다. 얼룩이 5개를 넘으면 안전 감독관 점검에서도 감점.
9. **🏦 증기 은행 (대출)**: 상점 탭에서 대출. 소액 운영자금 3,000(이자 8%·7일), 설비 개선 대출 8,000(12%·12일·Lv2), 증기왕 사업자금 20,000(18%·20일·Lv4). 원리금을 날짜로 나눠 매일 영업 마감 때 자동 상환하고, 모자라면 연체료 10%와 평판 −3. 한도는 4,000 + 레벨×3,000 + 평판×60. 언제든 하루치·완납 조기 상환 가능.
7. **🐈 고양이**: 상점에서 최대 3마리 입양. 따뜻한 난방 칸에서 낮잠, 분위기 +5, 근처 손님 만족도 상승. 사료비 하루 15.

10. **💡 조명**: 해가 지면(16:30~) 조명이 안 닿는 좌석 손님은 만족도 −8. 인테리어 › 💡조명 탭(가스 램프·샹들리에·아크등 줄·스탠드 가스등·테이블 램프·푸른 화로). 놓을 때 비추는 범위가 노란 원으로 보이고, 16시에 조명이 부족하면 알림.
11. **✥ 편집**: 설비·인테리어 탭의 [편집] 도구로 오브젝트를 클릭해 들어 올리고(R 회전, Del 철거, Esc 취소) 끌어서 위치를 정한 뒤 **✓ 여기에 두기**. 직사각형(소파·카운터·긴 테이블 등)은 90° 회전, 정사각형은 좌우 뒤집기. 오브젝트를 그냥 클릭해도 팝업에서 옮기기·회전·뒤집기·철거(50% 환급). 바닥·벽·천장 재질 카드를 고르면 **일괄 적용** 버튼.
12. **🎓 튜토리얼**: 새 게임에서 9단계 안내(보일러 → 급수관 → 바닥 → 카운터 → 싱크대 배관 → 조리 설비 → 좌석 → 조명 → 영업). 할 탭을 열어 주고, 고를 카드와 맵의 놓을 칸을 깜빡여 줌. 메뉴(☰)에서 다시 보기.
13. **☁️ 클라우드 저장**: 로그인(Firebase)하면 저장이 계정에도 올라가고, 다른 기기에서 로그인하면 더 최신 세이브를 불러옴.
14. **🎚 난이도** (메뉴 ☰, 기본 쉬움): 쉬움 = 평판이 떨어지지 않고 손님 인내심 ×1.3 · 보통 = 기본 규칙 · 어려움 = 평판 하락 ×1.5, 인내심 ×0.8, 석탄값 ×1.25. 평판이 떨어져도 화면에는 표시하지 않고, 손님은 칭찬이나 "또 올게요" 인사만 남김.
15. **🤖 자동 운영** (상단 버튼 또는 메뉴): 영업 시작·마감, 재고 적은 메뉴 조리와 진열, 재료·석탄 구매, 압력 배출, 누수·보일러 수리, 얼룩 닦기를 알아서 함. 하루 정산 창은 6초 뒤 자동으로 닫힘.
16. **🛠 패널 숨기기** (카메라 버튼 줄): 아래 설비·인테리어 패널을 접어 화면 전체로 감상. 상태는 기억됨.
17. **✓ 확정식 설치**: 오브젝트는 누르면 미리보기(깜빡이는 테두리)만 생기고, 끌어서 자리를 맞춘 뒤 아래 **✓ 설치**(또는 Enter)를 눌러야 지어짐. 배관·배관 철거도 드래그로 칸을 고른 뒤(고른 칸을 다시 누르면 빠짐) **✓ n칸 깔기**로 한 번에 확정·결제. ✕ 취소는 미리보기만 지움.

새 오브제: 증기 춤추는 풍선인형(급탕관 연결 시 춤춤), 몬스테라·산세베리아·고무나무, 청자 매병·백자 달항아리·옹기 항아리.

### 열·습도 모델

- 손실 `UA × (22° − 외기 기준온도)`를 보일러가 **온도조절**해서 채웁니다 (목표 22°).
- **내부 발열**(현열)이 그만큼 난방부하를 줄여 석탄을 아낍니다: 손님 70W, 바리스타 75W, 고양이 14–28W, 조리 중 기구, 증기 누수. 식물은 증산으로 현열 −8W/잠열 +8W.
- **잠열**은 실내 습도를 올립니다. 난방은 공기를 건조하게 합니다. 습도 35–60%가 쾌적하고, 너무 건조하거나 눅눅하면 만족도가 떨어집니다. 27° 이상으로 과열돼도 불만.
- 설비 탭 "설비 상태"에서 필요 난방 − 내부 발열 = 난방부하, 발열 항목별 W를 볼 수 있습니다.

### 마을과 카메라

- 가게 뒤로 원경 그림(assets/bg, 맑음·눈 버전)이 시차 스크롤로 깔리고, 안개 띠로 가까운 거리와 이어집니다. 원경 굴뚝에서 연기가 나고, 먼 하늘에 비행선·열기구가 지나가며, 눈 오는 날은 원경에도 잔눈이 내립니다 (굴뚝 위치는 js/town.js 의 VISTA_CHIMNEYS). 가까운 곳에는 이웃 가게들, 필지별 앞 풍경(운하와 증기선 / 비행선 정박장 / 뒷골목 지붕들), 하늘을 지나는 비행선, 밤에 켜지는 창문.
- 눈 오는 날은 땅·지붕·가게 벽에 눈이 쌓이고(눈보라면 빠르게, 맑으면 녹음), 돌풍에 눈이 휘날립니다.
- 작동 중인 보일러·조리기구·라디에이터 주변에 온기와 아지랑이가 보입니다.
- 건물은 잘린 벽 단면을 진하게, 외곽선을 둘러 표시하고, 건물 밖 마을은 살짝 흐리고 어둡게 그려 안팎이 구분됩니다.
- 휠/핀치로 확대·축소, 빈 곳 드래그로 이동(도구를 들고 있으면 칠하기), 우클릭·가운데 드래그는 항상 이동. 🏠 가게 / 🏙 마을 버튼.

하루는 08:00–20:00 (배속 1에서 약 3분). 레벨이 오르면 메뉴·설비·마감재가 해금됩니다.
