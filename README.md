# 스팀 & 빈즈

스팀펑크 도시의 빈 땅을 사서 배관을 깔고, 인테리어를 하고, 카페를 운영하는 도트 타이쿤 게임입니다.
빌드 과정 없이 `index.html`을 브라우저로 열면 됩니다 (`file://`로 열어도 동작).

## 게임 흐름

1. **땅 구매**: 크기·가격·유동인구가 다른 세 필지 중 하나를 고르고, 주인공(남/여)을 고릅니다.
2. **🔧 설비**: 중앙 증기 보일러 하나로 모든 설비를 돌립니다. 전기는 없습니다.
   - 왼쪽 벽의 **수도 인입구** → 보일러: **급수관**
   - 보일러 → 에스프레소 머신·주전자·오븐·싱크대: **급탕(증기)관**
   - 보일러 → 바닥 아래: **온수난방관** (깔린 칸이 따뜻해짐) / 주철 라디에이터
   - 배관이 설비 **밑이나 바로 옆 칸**을 지나가면 연결됩니다. 설비 탭에서는 바닥이 어두워지고 배관이 보입니다.
   - 보일러는 석탄을 태웁니다. 난방 칸이 많을수록, 눈보라일수록 빨리 탑니다.
3. **🎨 인테리어**: 바닥·벽·천장 마감재(드래그로 칠하기), 주방 설비, 가구, 장식, 천장 조명.
   가구는 바닥재 위에만 놓을 수 있고, 의자는 테이블과 상하좌우로 붙어야 좌석이 됩니다.
   마감재와 장식은 **분위기 점수**를 올려 손님 수와 팁을 늘립니다.
4. **☕ 운영**: 체크리스트(보일러·급수·석탄·카운터·위생 싱크대·조리 설비·좌석)를 채우면 영업 시작.
   설비를 눌러 메뉴를 만들고, 완성 말풍선을 눌러 카운터로 옮기면 바리스타가 손님에게 가져다줍니다.
   손님 만족도 = 분위기 + 실내 온도 − 기다린 시간 → 팁과 평판에 반영됩니다.
5. **🛒 상점**: 원두·우유·찻잎·밀가루·코코아·석탄 구매.

하루는 08:00–20:00 (배속 1에서 약 3분). 레벨이 오르면 메뉴·설비·마감재가 해금됩니다.

## 이벤트

| 이벤트 | 내용 |
| --- | --- |
| ❄ 눈보라 | 3시간. 실외 −16°. 실내가 따뜻하면 손님 ×1.4, 추우면 ×0.35. 석탄 소비 ×1.6 |
| ⚠ 보일러 압력 이상 | 압력이 계속 오름. 안전밸브를 열지 않으면 100에서 파열 → 모든 증기 설비 정지, 수리비 800 |
| 💧 배관 누수 | 무작위 배관 한 칸이 새서 그 너머로 흐름이 끊김. 클릭해서 수리 (40) |
| ⛏ 석탄 배달부 파업 | 4시간 동안 석탄 구매 불가 |
| 📈 석탄값 폭등 | 그날 석탄 가격 2배 |
| 🎈 비행선 축제 | 3시간 동안 손님 ×2.2 |
| 🎩 귀족 방문 | VIP 손님 2명 (팁·평판 큼, 분위기에 까다로움) |
| 🔍 증기 안전 감독관 | 압력·누수·위생 점검. 통과하면 포상금, 아니면 벌금 |

메뉴(☰) → 디버그에서 이벤트를 바로 발생시킬 수 있습니다.

## 조작

- 카드를 고르고 맵을 클릭/드래그 · 우클릭/ESC로 도구 해제
- Space 일시정지 · M 음악 켜기/끄기
- 진행은 localStorage에 자동 저장

## 구조

| 파일 | 내용 |
| --- | --- |
| `js/data.js` | 밸런스·콘텐츠 (필지, 마감재, 오브젝트, 레시피, 손님, 레벨) |
| `js/game.js` | 상태·시뮬레이션 (배관 네트워크, 손님, 바리스타, 이벤트, 저장) |

| `js/render.js` | 저해상도 월드 캔버스 + 고해상도 텍스트 캔버스, 조명, 날씨 |
| `js/ui.js` | 패널·팝업·입력 |
| `js/audio.js` | BGM |
