# 스팀 & 빈즈

스팀펑크 도시의 빈 땅을 사서 배관을 깔고, 인테리어를 하고, 카페를 운영하는 도트 타이쿤 게임입니다.
빌드 과정 없이 `index.html`을 브라우저로 열면 됩니다 (`file://`로 열어도 동작).

## 게임 흐름

1. **땅 구매**: 크기·가격·유동인구가 다른 세 필지 중 하나를 고르고, 주인공(남/여)을 고릅니다.
2. **🔧 설비**: 중앙 증기 보일러 하나로 모든 설비를 돌립니다. 전기는 없습니다.
   - 왼쪽 벽의 **수도 인입구** → 보일러: **급수관**
   - 보일러 → 에스프레소 머신·주전자·오븐·싱크대: **급탕(증기)관**
   - 보일러 → 바닥 아래: **온수난방관** (깔린 칸이 따뜻해짐) / 주철 라디에이터
   - 배관이 설비 **밑이나 바로 옆 칸**을 지나가면 연결됩니다. 설비 탭에서는 바닥이 어두워지고 배관이 보입니다.
   - 보일러는 석탄을 태웁니다. 난방 칸이 많을수록, 눈보라일수록 빨리 탑니다.
3. **🎨 인테리어**: 바닥·벽·천장 마감재(드래그로 칠하기), 주방 설비, 가구, 장식, 천장 조명.
   가구는 바닥재 위에만 놓을 수 있고, 의자는 테이블과 상하좌우로 붙어야 좌석이 됩니다.
   마감재와 장식은 **분위기 점수**를 올려 손님 수와 팁을 늘립니다.
4. **☕ 운영**: 체크리스트(보일러·급수·석탄·카운터·위생 싱크대·조리 설비·좌석)를 채우면 영업 시작.
   설비를 눌러 메뉴를 만들고, 완성 말풍선을 눌러 카운터로 옮기면 바리스타가 손님에게 가져다줍니다.
   손님 만족도 = 분위기 + 실내 온도 − 기다린 시간 → 팁과 평판에 반영됩니다.
5. **🛒 상점**: 원두·우유·찻잎·밀가루·코코아·석탄 구매.

6. **🏗 공간 확장**: 상점 탭에서 동쪽(+2열)/북쪽(+2행) 확장. 필지마다 최대 크기가 있고, 확장할수록 공사비와 필요 레벨이 오릅니다. 영업 전에만 공사 가능.
8. **☕ 커피 얼룩**: 손님이 다 마시고 일어날 때 가끔 좌석 옆 바닥에 커피를 쏟습니다. 얼룩 하나당 분위기 −2, 얼룩 옆 좌석 손님은 만족도 −5. 얼룩을 클릭하면 닦입니다. 얼룩이 5개를 넘으면 안전 감독관 점검에서도 감점.
9. **🏦 증기 은행 (대출)**: 상점 탭에서 대출. 소액 운영자금 3,000(기본 이자 3%·7일), 설비 개선 대출 8,000(5%·12일·Lv2), 증기왕 사업자금 20,000(8%·20일·Lv4). 이자는 난이도 배율: 쉬움 ×0.1(0.3~0.8%, 연체료 없음) · 보통 ×1 · 어려움 ×1.5(연체료 15%). 원리금을 날짜로 나눠 매일 영업 마감 때 자동 상환하고, 모자라면 연체료와 평판 −3(쉬움은 평판도 그대로). 한도는 4,000 + 레벨×3,000 + 평판×60. 언제든 하루치·완납 조기 상환 가능.
7. **🐈 고양이**: 상점에서 최대 3마리 입양. 따뜻한 난방 칸에서 낮잠, 분위기 +5, 근처 손님 만족도 상승. 사료비 하루 15.

10. **💡 조명**: 해가 지면(16:30~) 조명이 안 닿는 좌석 손님은 만족도 −8. 인테리어 › 💡조명 탭(가스 램프·샹들리에·아크등 줄·스탠드 가스등·테이블 램프·푸른 화로). 놓을 때 비추는 범위가 노란 원으로 보이고, 16시에 조명이 부족하면 알림.
    - 천장 조명(가스 램프·샹들리에·아크등 줄·실링팬·배관 장식)은 평소 화면에서 천장에 매달린 모습으로 반투명하게 보이고, 마을 쪽으로 멀어지면 천장 마감도 옅게 덮여 보임.
    - 테이블 램프·테이블 촛대는 테이블·카운터 위에만 올림(layer `top`). 테이블을 옮기거나 돌리면 같이 움직이고, 테이블을 치우면 함께 환급.
    - 벽걸이 조명(layer `wall`): 벽 가스등·황동 벽 랜턴·증기관 전구 — 위쪽·양옆 벽(모서리·문·인입구 제외)에 걸고, 빛은 방 안쪽으로 비춤. 위쪽 벽은 정면 모습, 양옆 벽은 벽에 붙어 방 안쪽으로 튀어나온 옆모습(`Sprites.wallMount`, 오른쪽 벽은 좌우 반전). 공간 확장 때 벽을 따라 옮겨짐.
11. **✥ 편집**: 설비·인테리어 탭의 [편집] 도구로 오브젝트를 클릭해 들어 올리고(R 회전, Del 철거, Esc 취소) 끌어서 위치를 정한 뒤 **✓ 여기에 두기**. 직사각형(소파·카운터·긴 테이블 등)은 90° 회전, 정사각형은 좌우 뒤집기. 오브젝트를 그냥 클릭해도 팝업에서 옮기기·회전·뒤집기·철거(50% 환급). 바닥·벽·천장 재질 카드를 고르면 **일괄 적용** 버튼.
12. **🎓 튜토리얼**: 새 게임에서 9단계 안내(보일러 → 급수관 → 바닥 → 카운터 → 싱크대 배관 → 조리 설비 → 좌석 → 조명 → 영업). 할 탭을 열어 주고, 고를 카드와 맵의 놓을 칸을 깜빡여 줌. 안내 상자는 제목을 눌러 접고 펼침(모바일은 기본으로 접힘, 단계가 바뀌면 반짝). 메뉴(☰)에서 다시 보기.
13. **☁️ 클라우드 저장** (Firebase, `js/firebase-init.js`의 `Cloud`): 타이틀 화면에서 바로 로그인/회원가입/비밀번호 재설정. 로그인하면 클라우드 세이브 요약(일차·돈·레벨·저장 시각)을 보여 주고 '☁️ 클라우드에서 이어하기 / 💻 이 기기 진행으로 이어하기 / 새 게임' 중 고름(더 최근 것 표시, 덮어쓰기 전엔 확인). 고르기 전에는 절대 클라우드에 올리지 않음. 게임 중 로그인하면 어느 진행을 쓸지 묻고, 클라우드를 고르면 내려받아 새로고침 후 이어서 시작. 올리기 전에 다른 기기가 그사이 저장했는지 확인해서, 그렇다면 덮어쓰지 않고 멈춘 뒤 다시 물음.
14. **🎚 난이도** (메뉴 ☰, 기본 쉬움): 쉬움 = 평판이 떨어지지 않고 손님 인내심 ×1.3 · 보통 = 기본 규칙 · 어려움 = 평판 하락 ×1.5, 인내심 ×0.8, 석탄값 ×1.25. 평판이 떨어져도 화면에는 표시하지 않고, 손님은 칭찬이나 "또 올게요" 인사만 남김.
15. **🤖 자동 운영** (상단 버튼 또는 메뉴): 영업 시작·마감, 재고 적은 메뉴 조리와 진열, 재료·석탄 구매, 압력 배출, 누수·보일러 수리, 얼룩 닦기를 알아서 함. 하루 정산 창은 6초 뒤 자동으로 닫힘.
16. **🛠 패널 숨기기** (카메라 버튼 줄): 아래 설비·인테리어 패널을 접어 화면 전체로 감상. 상태는 기억됨.
17. **✓ 확정식 설치**: 오브젝트는 누르면 미리보기(깜빡이는 테두리)만 생기고, 끌어서 자리를 맞춘 뒤 아래 **✓ 설치**(또는 Enter)를 눌러야 지어짐. 배관·배관 철거도 드래그로 칸을 고른 뒤(고른 칸을 다시 누르면 빠짐) **✓ n칸 깔기**로 한 번에 확정·결제. ✕ 취소는 미리보기만 지움.
    - 바닥·벽·천장 칠하기도 드래그로 칸을 고르면 새 재질이 반투명하게 미리 보이고 [✓ n칸 칠하기]로 한 번에 결제. [🖌 전체 선택]은 칠할 수 있는 칸을 모두 고르기만 함. 오브젝트 철거 도구도 치울 것을 눌러 고른 뒤 [✓ n개 철거].
18. **📱 모바일 전체화면**: 모바일에서 [새 게임]/[이어하기]를 누르면 전체화면으로 전환(안드로이드 크롬 등). 메뉴(☰)에서 켜고 끄기. 아이폰 사파리는 웹 전체화면을 지원하지 않으므로 공유 → [홈 화면에 추가]로 설치하면 주소창 없이 전체화면 앱으로 실행(`manifest.webmanifest`, 아이콘 `assets/icon-*.png`).
19. **🔊 효과음·증기 환경음** (`js/sfx.js`, 파일 없이 WebAudio 합성): 에스프레소 추출(쉭+보글)·주전자·오븐, 완성 종, 컵 소리, 서빙, 결제 동전(팁이면 반짝음), 손님 입장 종, 설치·배관 쇳소리·철거, 칠하기, 얼룩 닦기, 압력 배출, 수리, 보일러 파열, 이벤트 기적, 개점·마감 종, 레벨업, 오류음. 마을 쪽으로 줌아웃할수록 가게 소리는 작아지고 증기 도시 환경음(새는 증기, 공장 웅웅, 증기기관 칙칙폭폭, 멀리 기적, 밸브 푸슉, 망치 쇳소리)이 커짐. 가게 안에서도 보일러가 돌면 8~20초에 한 번쯤 증기 쉭·푸슉, 배관 쿵쿵(워터해머), 라디에이터 틱틱, 보일러 칙칙 소리가 남(압력이 높으면 더 자주, 작은 기적). 메뉴(☰) 맨 위 🔊 소리에서 음악·효과음·증기·환경음 볼륨 슬라이더(기억됨), 효과음 켜기/끄기는 따로. 메뉴의 닫기 버튼은 맨 위에 고정.
20. **🛒 구매 확인창**: 재료·석탄은 [구매]를 누르면 확인창에서 묶음 수를 −10/−/＋/+10/최대 또는 직접 입력으로 정하고 합계·남는 돈·구매 후 보유량을 확인한 뒤 구매. 고양이 입양·대출·공간 확장도 확인창을 거침.
21. **📱 모바일 시트 패널** (화면 폭 860px 이하): 평소엔 맵을 크게 보고 아래에 탭 줄만 표시. 탭을 누르면 패널이 화면을 덮는 시트로 열리고, 배치 도구(설비·가구·배관·편집·재질)를 고르면 자동으로 맵으로 돌아감. 재질의 [전체 칠하기]는 맵 아래 도구 막대에. 시트는 [🗺 맵으로 ✕]로 닫기.
22. **👥 직원 고용** (운영 탭): 고용비 + 일급(영업 마감 때 지급, 정산표에 표시). 직원 수 한도 = 2 + (레벨−1)/2. 🍽 서빙 직원(Lv1, 최대 4) — 주인공과 함께 서빙 대기열을 나눠 동시 서빙 · ☕ 보조 바리스타(Lv2, 최대 2) — 쉬는 조리 설비로 진열이 적은 메뉴를 만들고 완성품을 카운터로 · 🧹 청소부(Lv2, 최대 2) — 얼룩을 찾아가 닦음 · 🔧 보일러공(Lv3, 1명) — 압력 배출, 누수 수리, 보일러 수리, 석탄 주문. 직원은 맵에서 걸어 다니며 일하고(머리 위 리본 색 = 역할), 클릭하면 하는 일 확인·해고.
23. **🤖 증기 로봇 직원** (운영 탭, 사람 직원 한도와 별도 — 1 + 레벨/3 대): 일급 대신 매일 마감 때 석탄을 먹고, 보일러가 멈추면 그 자리에서 정지(머리 위 깜빡이는 경고). 걸을 때 증기를 뿜음. 🤖 황동 서빙봇(Lv3, 2,400, 석탄 3/일, 빠름) · 구리 청소봇(Lv2, 1,500, 석탄 2/일, 바퀴라 느림) · 녹청 바리스타봇(Lv5, 3,600, 석탄 4/일). 그림은 코드로 그린 도트(`drawRobotArt`).
24. **🍠 군고구마**: 보일러를 클릭하면 군고구마(고구마 1 → 5개, 25분, 🪙8)를 구울 수 있어 보일러만 있어도 판매·개점 가능. 고구마는 상점에서 10개 12.
25. **👔 직원 유니폼**: 사람 직원은 주인공과 반대 성별 캐릭터 시트를 쓰고, 목 아래 옷만 역할별 색으로 다시 칠함(서빙 남색 · 바리스타 초록 · 청소부 보라 · 보일러공 빨강, `Sprites.charTint`). 픽셀을 못 읽는 환경(file://)에서는 색상 혼합으로 대신 물들임.
26. **🪑 가구 추가 + 자연스러운 회전**: 주철 카페 테이블·대리석 사각 테이블·항해 지도 테이블(2칸)·황동 바 스툴·벤트우드 철제 의자·윙백 체어·교회 장의자(2칸)·가죽 부스 소파(2칸)·모자 걸이·찻잔 진열장. 회전은 그림을 그냥 90° 돌리지 않고 방향별 그림을 씀 — 의자·안락의자는 앞/오른쪽/뒤/왼쪽 4방향, 소파·긴 테이블·카운터·벤치 등 2칸짜리는 앞/오른쪽/왼쪽 옆모습(`drawSide`/`drawBack`). 의자는 직접 돌리지 않으면 옆 테이블 쪽을 자동으로 바라봄. 옆모습 그림이 없는 장식은 덤불류는 두 덩이를 앞뒤로, 나머지는 폭을 줄여 세움. 예전 세이브의 '세로+뒤집기'는 왼쪽 방향으로 자동 변환.

새 오브제: 증기 춤추는 풍선인형(급탕관 연결 시 춤춤), 몬스테라·산세베리아·고무나무, 청자 매병·백자 달항아리·옹기 항아리.

### 열·습도 모델

- **외피 단열**: 열손실계수 UA = 벽(바깥 테두리 칸 U0 2.4) + 바닥(칸당 1.3) + 천장(칸당 1.4) W/K. 마감재마다 열저항 r 이 있어 그 칸은 U = 1/(1/U0 + r) 로 줄어듦 → 필요 난방(UA × 온도차)이 감소. 카드에 '🧱 열손실 −n%' 표시. 단열 좋은 것: 페르시아 융단·진홍 카펫·쪽모이/헤링본 원목, 서가 벽·마호가니 패널, 격자 우물천장·하늘 프레스코·석고. 스테인드글라스 창·유리 돔 채광창은 r<0 이라 오히려 열이 더 샘. 설비 탭에 벽·바닥·천장별 UA 와 마감재 절감률 표시.

- 손실 `UA × (22° − 외기 기준온도)`를 보일러가 **온도조절**해서 채웁니다 (목표 22°).
- **내부 발열**(현열)이 그만큼 난방부하를 줄여 석탄을 아낍니다: 손님 70W, 바리스타 75W, 고양이 14–28W, 조리 중 기구, 증기 누수. 식물은 증산으로 현열 −8W/잠열 +8W.
- **잠열**은 실내 습도를 올립니다. 난방은 공기를 건조하게 합니다. 습도 35–60%가 쾌적하고, 너무 건조하거나 눅눅하면 만족도가 떨어집니다. 27° 이상으로 과열돼도 불만.
- 설비 탭 "설비 상태"에서 필요 난방 − 내부 발열 = 난방부하, 발열 항목별 W를 볼 수 있습니다.

### 마을과 카메라

- 가게 뒤로 원경 그림(assets/bg, 맑음·눈 버전)이 시차 스크롤로 깔리고, 안개 띠로 가까운 거리와 이어집니다. 원경 굴뚝에서 연기가 나고, 먼 하늘에 비행선·열기구가 지나가며, 눈 오는 날은 원경에도 잔눈이 내립니다 (굴뚝 위치는 js/town.js 의 VISTA_CHIMNEYS). 가까운 곳에는 이웃 가게들, 필지별 앞 풍경(운하와 증기선 / 비행선 정박장 / 뒷골목 지붕들), 하늘을 지나는 비행선, 밤에 켜지는 창문.
- 눈 오는 날은 땅·지붕·가게 벽에 눈이 쌓이고(눈보라면 빠르게, 맑으면 녹음), 돌풍에 눈이 휘날립니다.
- 작동 중인 보일러·조리기구·라디에이터 주변에 온기와 아지랑이가 보입니다.
- 건물은 잘린 벽 단면을 진하게, 외곽선을 둘러 표시하고, 건물 밖 마을은 살짝 흐리고 어둡게 그려 안팎이 구분됩니다.
- 휠/핀치로 확대·축소, 빈 곳 드래그로 이동(도구를 들고 있으면 칠하기), 우클릭·가운데 드래그는 항상 이동. 🏠 가게 / 🏙 마을 버튼.

하루는 08:00–20:00 (배속 1에서 약 3분). 레벨이 오르면 메뉴·설비·마감재가 해금됩니다.
